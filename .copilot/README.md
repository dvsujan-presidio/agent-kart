# .copilot

Project context for GitHub Copilot / Microsoft Copilot.

- `instructions.md`: project rules, layout, commands (also copied to `.github/copilot-instructions.md`, where GitHub Copilot reads it automatically)
- `microsoft-services.md`: which Microsoft services are used, and which are not
- `prompts/`: reusable prompts (`run-and-verify`, `add-real-store`)

Keep `instructions.md` and `.github/copilot-instructions.md` identical: `cp .copilot/instructions.md .github/copilot-instructions.md`.
